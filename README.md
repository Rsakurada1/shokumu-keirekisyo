## 職務要約

2022年4月に株式会社アルテクナへ入社し、C言語を中心とした3か月間の研修を受講しました。その後、大手自動車メーカーのカーナビシステムにおけるセキュリティ開発に11か月、大手カメラメーカーのマイコン制御システム開発に3か月従事しました。

2023年12月に株式会社アルテクナを退職し、2024年2月にSky株式会社へ入社しました。駐車場営業支援Webアプリケーション開発、販売管理システムのモダナイゼーション開発、自動車メーカー向けデータ解析・可視化Webアプリケーションのフロントエンド開発に従事しました。

2026年7月にatama plus株式会社へ入社し、現在はプトダクトマネジメントチームでプロダクトを横断的に開発を行っています。

| --- | --- |

老朽化した販売管理システムをReact、NestJS、AWSで再構築するプロジェクトに参画しました。散在していたサービスをAWSへ集約して運用・保守性を改善するとともに、開発基盤と開発体制の立ち上げ、メンバー育成に取り組みました。

**担当業務**

- 設計、実装、テストを含む機能開発
- レガシーシステムの調査と顧客ヒアリングによる仕様確認
- 利用者ヒアリングと説明会を通じたUI/UX改善
- テスト自動化、品質・セキュリティゲート、成果物管理、自動デプロイを含むCI/CD構築
- 顧客側開発メンバー1名の進捗・課題の可視化と開発支援

**主な実績**

- **APIの登録・更新・削除・検索機能:** 更新履歴を保持しながら複数属性と更新回数から業務キーを採番する仕様に対し、悲観ロックを実装しました。件数参照から採番、登録完了までを排他的に制御し、同時実行時の採番重複を防止しました。
- **メール送信機能:** AWS SQSとLambdaを利用した非同期アーキテクチャを設計・実装しました。登録・更新・削除ごとにテンプレートを切り替えられる構成とし、アーキテクチャ図を用いた事前レビューで設計リスクと手戻りを抑えました。
- **フロントエンド開発基盤:** 共通コンポーネントをパッケージ化し、他部署でも利用できる運用を整備しました。Storybookを導入し、実装方法、動作、UI仕様を共有できるようにしました。
- **若手メンバー支援:** PRレビューや設計相談を通じ、設計意図、可読性、保守性、テスト観点を整理してフィードバックしました。実装相談やテストケースの洗い出しも支援し、段階的な移譲によって独力でタスクを遂行できる状態へ導きました。
- **CI/CD整備:** developブランチへのマージを契機に単体テストを実行し、成功時のみ開発環境へ自動デプロイする品質ゲートを構築しました。テストレポートとビルド成果物の出力・管理も自動化しました。
- **脆弱性診断ゲート:** npm依存関係の脆弱性診断をパイプラインへ組み込み、Criticalレベルの脆弱性を検出した場合はデプロイを停止する仕組みを実装しました。診断レポートも成果物として管理できるようにしました。

#### 駐車場営業支援Webアプリケーション開発（SFA）

| 項目 | 内容 |
| --- | --- |
| 期間 | 2024年2月 - 2025年1月 |
| 職種 | フルスタックエンジニア |
| 役割 | メンバー |
| チーム規模 | 10名 |
| 利用技術 | Java、JavaScript、TypeScript、jQuery、SQL、Vue.js |

顧客からの要望を基に、駐車場営業支援Webアプリケーションの基本設計から結合テストまでを担当しました。メンバーが作成した設計書とコードのレビューも行いました。

**主な実績**

- **駐車場営業案件サジェスト検索の高速化:** 実行計画を分析し、検索処理と実行計画作成にそれぞれ15秒を要していることを特定しました。適切なヒント句を付与し、検索時間を30秒から10秒へ短縮しました。
- **地図画面のGC頻発問題を解決:** 広範囲表示時にも不要な物件・案件検索が実行されていることを特定し、ズームレベルに応じて自動検索を抑制するロジックを提案・実装しました。GCの頻発を解消し、画面性能とユーザー体験を改善しました。
- **契約法人情報の共有機能:** 口頭やメールで共有されていた契約法人情報をSFA上で一元管理し、掲示板形式で共有できる機能を開発しました。外部APIから企業情報を自動取得・反映する仕組みも構築し、営業部門の情報共有と生産性を改善しました。
- **カーシェアリング案件管理機能:** Excelで管理されていた案件をSFAへ集約し、既存の駐車場物件管理機能と紐付けました。データとフォーマットを統一し、物件単位で直感的に検索・操作できるUIを実現しました。
- **勉強会の主催:** 定時後に継続的な勉強会と情報交換会を開催し、新人の業務理解とスキル向上を支援しました。資格取得者の輩出とチーム内の学習文化醸成につなげました。
